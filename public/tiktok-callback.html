Authorisation code

Kept hidden on purpose. If you are screen-recording this page for the app review, copy the code without revealing it — an authorisation code should not appear in an uploaded video.

This code is single-use and short-lived, usually about ten minutes. It must be exchanged for a refresh token on the server, because that exchange needs the client secret, which never belongs in a browser.
